📱 My Notes – Android Application

My Notes is a modern, feature-rich note-taking application for Android, designed to be simple, intuitive, and highly efficient.
It allows users to quickly capture their ideas with text or voice, powered by a clean UI and modern Android development practices.

A key highlight of the application is the Voice-to-Text functionality, allowing hands-free note creation by converting speech into text automatically.

✨ Features

📝 Create, Read, Update, and Delete notes

🎙 Voice-to-Text note creation

🤖 (Optional) AI-powered summarization using Gemini API

🔍 Search notes instantly using SearchView

📦 Offline storage using Room Database

🏗 Built with MVVM Architecture

🧭 Seamless screen navigation using Navigation Components + Safe Args

📍 Clean & minimalist Material UI

🚀 Getting Started

Follow these steps to run the project locally.

Prerequisites

Android device/emulator running API 26+

Installation

Clone the repository

Open in Android Studio

Run the app
